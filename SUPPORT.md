# Getting help

- Setup or behavior defect: use the bug-report issue form with `lab doctor` output and a minimal
  reproduction.
- Feature or workflow proposal: use the proposal form and state the user outcome before the design.
- Security or private data: follow [`SECURITY.md`](SECURITY.md); never post it publicly.
- General operation: start with the [five-minute guide](docs/lab/quickstart.md) and
  [operator guide](docs/lab/operator-guide.md).

Catfish Lab is currently maintained on a best-effort basis. A DELAYED Logbook event reports tool or
provider failure inside a story; it is not a maintainer support ticket.
