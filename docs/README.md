AI coding is quick at producing an answer. Catfish Lab makes the path to that answer inspectable:
what the user asked, what each specialist concluded, what failed, what was tested, and who accepted
the result.

The ordinary route is deliberately short: **request → scope → build → attack → judge → accept**.
The full laboratory remains one key away when uncertainty deserves hypotheses, blind alternatives,
and an experiment.
